# self-introduction · 个人主页

我的第一个个人主页，使用纯 HTML + CSS 制作，不依赖任何框架。

👉 **在线访问**：<https://isabexy.github.io/self-introduction>

## ✨ 页面内容

- 🌱 关于我 —— 自我介绍与兴趣标签
- 🚀 正在学习 —— Python / HTML·CSS / 教育技术课程
- 🎨 我的作品 —— 个人主页、GitHub 仓库、摄影集
- 📮 联系我 —— GitHub 主页入口

## 🛠 技术要点

- 语义化 HTML 结构（`header` / `main` / `section` / `nav`）
- CSS 自定义属性（变量）管理配色，主题与头像插画呼应
- `position: fixed` + 毛玻璃效果的吸顶导航
- Grid 自适应布局，手机端响应式适配
- 图片压缩优化（大图从 5.5MB 压缩至 655KB）
